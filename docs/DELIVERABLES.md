## Generated Output Files (Created During Use)

When running the application, these files are automatically created:

### In data/ directory:
- **modifications_log.json**
  - JSON array of all modifications made
  - Each entry includes timestamp, column, old/new values
  - Persistent across app restarts

- **data_state.json**
  - JSON snapshot of current data state
  - Records-oriented format
  - Updated when saving modifications

- **data_modified.csv**
  - CSV export of current data
  - Created when clicking "Export to CSV"

### In data/processed/ directory:
- **data_transformed.csv**
  - Final transformed data
  - Generated by process_modifications.py

- **modifications_audit.csv**
  - Human-readable change audit trail
  - One row per modification
  - Includes timestamp, column, before/after values

- **modifications.sql**
  - SQL UPDATE statements
  - Ready to execute against database
  - One statement per modification

- **summary.json**
  - Change statistics
  - Lists modified columns and rows
  - Total modification count

## Integration Patterns

### Pattern 1: Direct Data Updates
```python
import pandas as pd
import json

df = pd.read_csv("data/dummy_data_50rows.csv")
mods = json.load(open("data/modifications_log.json"))

for mod in mods:
    d = mod["details"]
    df.at[d["row_index"], d["column"]] = d["new_value"]

df.to_csv("output.csv", index=False)
```

### Pattern 2: Database Updates
```bash
# Execute generated SQL
cat data/processed/modifications.sql | psql mydb

# Or pipe to your database client
cat data/processed/modifications.sql | mysql mydb
```

### Pattern 3: Audit & Compliance
```python
# Load audit trail
audit = pd.read_csv("data/processed/modifications_audit.csv")

# Filter by date
recent = audit[audit['timestamp'] > '2024-01-21']

# Export for compliance
recent.to_csv("compliance_report.csv")
```
